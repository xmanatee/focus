Common questions

Why does Focus Blocks need Screen Time permission?

Focus Blocks uses Apple's Screen Time frameworks to shield the apps, sites, and categories you choose. iOS requires this permission before any app can apply those shields.

Why does Focus Blocks need Android Accessibility access?

Android does not provide the same Screen Time framework as iOS. Focus Blocks uses window-change events to identify the foreground app, compare it locally with your enabled schedules, and return you to the Focus Blocks blocked screen when necessary. It cannot retrieve window content and does not read text, capture keystrokes, take screenshots, perform gestures, or share Accessibility data.

How do I turn Android blocking on or off?

For an APK installed outside an app store on Android 13 or later, use the setup card in Focus Blocks to open App info. Tap the three-dot menu, choose Allow restricted settings if shown, confirm with your screen lock, and return to Focus Blocks. Use the next setup action, review the Accessibility disclosure, then enable Focus Blocks app blocking. Android requires this order and does not let apps approve the restricted setting themselves. See Android's official restricted-settings guide.

Why is an Android block not applying?

Confirm that Accessibility access is still enabled, the block is enabled on this device, at least one installed app is selected, and the current time is inside the configured blocking period. On Xiaomi HyperOS, if access later turns itself off, open Focus Blocks App info, set Battery saver to No restrictions, enable Background autostart, and then re-enable the Accessibility service. Android currently supports scheduled app blocking; daily budgets, app categories, websites, iCloud sync, notifications, and Lock-in are not available there.

Why did my synced block not block apps on a new iPhone?

Rules can sync through your iCloud account, but Screen Time app selections are private tokens that belong to one device. Open any block marked "Pick apps here" on the new device and confirm the apps there.

What is the difference between a schedule and a daily budget?

A schedule controls when selected apps are blocked or allowed. A daily budget gives selected apps a limited number of minutes per day, then blocks them after the budget is used. Some blocks can use both.

How do I unblock an app temporarily?

Wait for the rule to stop applying. If you set a Lock-in setup window, edits unlock during that window so you can change the block intentionally rather than on impulse.

I deleted the app and shields stayed on. How do I clear them?

Go to Settings -> Screen Time and clear remaining restrictions. iOS can keep shields after the controlling app is removed so restrictions survive deletion and reinstall attempts.

Does Focus Blocks work for parental control?

No. Focus Blocks is self-directed. It is not a parental-control product and does not manage other people's devices. For parental control, use Apple's built-in Screen Time with Family Sharing.

Which iOS versions are supported?

Focus Blocks requires iOS 18 or later.

Which Android versions are supported?

Focus Blocks requires Android 7.0 or later.

How do I install or update the Android APK?

Download the latest signed APK, open it, and approve installation from your browser if Android asks. On Android 13 or later, complete Allow restricted settings in App info before enabling Accessibility; Focus Blocks guides new installations through this sequence. Installing a newer APK updates the existing app while preserving its local data. You can compare the download with the published SHA-256 checksum.
