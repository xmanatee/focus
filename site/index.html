Questions

What people usually ask before installing.

Is Focus Blocks parental control?

No. It is self-directed and designed for your own devices. It does not manage other people's devices.

Does it read which apps I use?

No. Apple devices use private Screen Time selections. On Android, the Accessibility service compares only the foreground app identifier with your local rules. Focus Blocks does not run analytics or send usage data to a server.

Why does each Apple device ask me to confirm apps?

Screen Time selections are private device-local tokens. Rules can sync through iCloud, but app selections must be confirmed on each iPhone or iPad.

What version of iOS do I need?

Focus Blocks requires iOS 18 or later.

How do I install the Android APK?

Download the signed APK from this page, open it, and approve installation from your browser when Android asks. Future APK releases signed with the same Focus Blocks key can update the installed app.
