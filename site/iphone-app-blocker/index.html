App blocking

How to block distracting apps on iPhone.

Choose the apps that interrupt you, then decide when to block them. Focus Blocks uses Apple's Screen Time permission to apply a blocking screen during a schedule or after a daily allowance.

View on the App StoreRead support

Core app-blocking modes

Block during schedule

Keep distracting apps out during work, school, sleep, or morning routines.

Allow only during schedule

Make selected apps unavailable by default and only open during a chosen window.

Daily budget

Use a hard cap for apps that are fine briefly but hard to stop.

Set up your first app block

  1. Install and grant access. Install Focus Blocks on an iPhone or iPad running iOS 18 or later, open it, and approve Screen Time access when prompted.
  2. Choose a small set of distractions. Add a block and use Apple's picker to select the apps or categories you want to restrict. Leave essential communication and work apps outside the selection.
  3. Choose one rule. For a work session, block during a schedule. If you want an app available only at lunch, allow it only during that window. For a daily allowance, choose a budget.
  4. Save and verify. Enable the block on this device. During an active scheduled period, open one of the selected apps and confirm that its blocking screen appears.

Which rule should you choose?

A schedule answers "When can I use this app?" A daily budget answers "How much can I use it today?" Start with the one that matches your problem. For example, a weekday 09:00-12:00 block keeps feeds out of a morning work session; a ten-minute daily budget leaves a short allowance without opening the whole afternoon.

Blocking the YouTube app and blocking its website are separate choices. If you also watch in a browser, configure the website selection too. The YouTube blocking guide covers that distinction, and the daily limits guide explains budgets.

Check protection before adding Lock-in

Start with a short scheduled block so you can check the selection and timing. Once it behaves as expected, you can add a Lock-in setup window to restrict when you edit the rule. Choose a window when you will be able to review your settings.

If a selected app still opens, check Screen Time access, whether the block is enabled on this device, and whether its schedule is active. A synced rule still needs a local app selection on every iPhone or iPad. Follow the iPhone setup checklist before changing the rule.

Private by default

There is no Focus Blocks account, analytics SDK, ad SDK, or backend. Rules can sync through your own iCloud account, while Screen Time app selections stay device-local.

For setup help, use Focus Blocks support to check Screen Time permission, daily budgets, synced rules, and per-device app selections.
